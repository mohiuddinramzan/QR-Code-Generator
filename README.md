# 📱 QR Code Maker

একটি সাধারণ, দ্রুত এবং সুন্দর QR কোড জেনারেটর — শুধুমাত্র **HTML, CSS ও JavaScript** দিয়ে তৈরি। কোনো ব্যাকএন্ড লাগবে না, সরাসরি ব্রাউজারেই কাজ করে।

🔗 **Live Demo:** [এখানে ক্লিক করুন](https://তোমার-ইউজারনেম.github.io/qr-code-maker/)
*(GitHub Pages লিংক দিয়ে আপডেট করো)*

---

## ✨ ফিচারসমূহ

- 🔤 যেকোনো টেক্সট বা URL থেকে QR কোড তৈরি
- 📶 WiFi QR কোড তৈরি (SSID, পাসওয়ার্ড, এনক্রিপশন সহ) — স্ক্যান করলেই WiFi কানেক্ট হয়ে যায়
- 🎨 QR কোডের রং এবং ব্যাকগ্রাউন্ড কালার কাস্টমাইজ করার সুবিধা
- 📏 একাধিক সাইজ অপশন (200px থেকে 500px)
- 💾 তৈরি করা QR কোড PNG ফরম্যাটে ডাউনলোড করার সুবিধা
- 📱 মোবাইল-ফ্রেন্ডলি রেসপনসিভ ডিজাইন
- 🇧🇩 বাংলা ইউজার ইন্টারফেস

---

## 🛠️ ব্যবহৃত প্রযুক্তি

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- [qrcode.js](https://github.com/davidshimjs/qrcodejs) লাইব্রেরি (CDN থেকে লোড করা)

## 🚀 কীভাবে ব্যবহার করবেন

### লোকালি চালাতে চাইলে:
```bash
git clone https://github.com/তোমার-ইউজারনেম/qr-code-maker.git
cd qr-code-maker
```
তারপর `index.html` ফাইলটি সরাসরি ব্রাউজারে খুলুন।

### GitHub Pages-এ ডিপ্লয় করতে:
1. Repo এর **Settings** → **Pages**-এ যান
2. Branch হিসেবে `main` এবং folder হিসেবে `/root` সিলেক্ট করুন
3. **Save** করুন — কিছুক্ষণের মধ্যেই সাইট লাইভ হয়ে যাবে
